# CRUD Diary App

Aplikasi Buku Harian untuk mencatat aktivitas dan suasana hati sehari-hari.

## Fitur Utama
- **Home**: Daftar semua catatan harian, fitur pencarian, dan pull-to-refresh.
- **Tambah Diary**: Form untuk membuat catatan baru dengan pilihan mood (emoji).
- **Detail Diary**: Lihat catatan secara lengkap dan hapus jika perlu.
- **Edit Diary**: Perbarui catatan yang sudah ada dengan mudah.
